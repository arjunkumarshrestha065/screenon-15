SAFE SIGNAGE PLAYER APK

This is the safer alternative if antivirus flags autorun/launcher/settings-control APK.

Removed risky features:
- No BOOT_COMPLETED autorun permission.
- No Home/Launcher mode.
- No Open Android Settings command.
- No Exit App bridge.
- No hidden admin menu.

Kept useful features:
- Manual launch from app icon.
- Pairing code.
- Server playlist duration control.
- Auto repeat.
- Random transitions.
- Background download.
- Removable/internal app storage download.
- Offline playback from already downloaded media.
- Reset Server button on setup screen.

Build method:
1. Extract this ZIP.
2. Upload extracted files/folders to GitHub root.
3. Go to Actions.
4. Run Build Safe Android APK.
5. Download safe-signage-player-debug-apk artifact.
6. Extract and install app-debug.apk.

Autostart alternative:
Use Android TV box setting or trusted third-party launcher/autostart app instead of risky APK permissions.
